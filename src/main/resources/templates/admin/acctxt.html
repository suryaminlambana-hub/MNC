Generate File ACCTXT

Otorisasi checker hanya menandai data sebagai disetujui — file ACCTXT-nya dibuat di sini, satu file berisi gabungan export. Ada dua tombol dan keduanya menyusun file yang sama, bedanya di isi: tombol Hari Ini untuk persetujuan hari ini (dipakai sehari-hari), tombol Susun Ulang untuk memperbaiki isi file memakai persetujuan 3 hari terakhir.

Nama filenya selalu ACCTXT.YYMMDD — mengikuti tanggal hari ini saat tombol ditekan, bukan tanggal data yang dipilih. Menekan tombolnya lagi hari ini tidak membuat file kedua: file yang sama disusun ulang berisi semuanya. Filenya terkirim ke /home/ftpuser.

Susun ulang dari tanggal lampau

Hanya 3 hari terakhir yang bisa dipilih: s/d . Hari ini tidak termasuk — untuk persetujuan hari ini pakai tombol di atas. Yang diambil adalah file ACCTXT tanggal tersebut, bukan export satu per satu. Kalau satu tanggal pernah digenerate lebih dari sekali, yang dipakai versi terakhirnya — yang sudah tertimpa tidak ikut. File-file itu digabung jadi satu file bertanggal hari ini. Tombol ini tidak mengeluarkan apa pun dari daftar di atas: export tetap tercatat sebagai penghuni file tanggal asalnya, sehingga rentang yang sama bisa disusun ulang berkali-kali.
