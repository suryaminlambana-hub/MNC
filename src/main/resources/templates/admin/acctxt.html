Generate File ACCTXT

Otorisasi checker hanya menandai data sebagai disetujui — file ACCTXT-nya dibuat di sini, satu file berisi gabungan export. Ada dua tombol dan keduanya menyusun file yang sama, bedanya di isi: tombol Hari Ini untuk persetujuan hari ini (dipakai sehari-hari), tombol Susun Ulang untuk memperbaiki isi file memakai persetujuan 3 hari terakhir.

Nama filenya selalu ACCTXT.YYMMDD — mengikuti tanggal hari ini saat tombol ditekan, bukan tanggal data yang dipilih. Menekan tombolnya lagi hari ini tidak membuat file kedua: file yang sama disusun ulang berisi semuanya. Filenya terbit di C:\inetpub\ftproot.
