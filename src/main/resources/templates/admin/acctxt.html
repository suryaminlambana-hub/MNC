Generate File ACCTXT

Menggabungkan seluruh export yang sudah disetujui checker pada rentang tanggal terpilih menjadi satu file ACCTXT di folder hasil export. Otorisasi checker hanya menandai data sebagai disetujui — filenya dibuat di sini.

Nama filenya selalu ACCTXT.YYMMDD — mengikuti tanggal hari ini saat tombol ditekan, bukan tanggal data yang dipilih. Menekan tombolnya lagi hari ini tidak membuat file kedua: file yang sama disusun ulang berisi semuanya.

Hanya 3 hari terakhir yang bisa dipilih: s/d . Tanggal di luar itu ditolak.
