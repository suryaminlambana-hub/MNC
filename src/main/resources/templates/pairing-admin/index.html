Pasangan Admin - Admin Approval

Tetapkan admin mana saja yang berada di bawah pengawasan seorang Admin Approval. Pasangan ini menentukan siapa melihat jejak siapa di Audit Trail Admin: Admin Approval melihat jejak admin yang dipegangnya, sedangkan admin hanya melihat jejaknya sendiri beserta keputusan atas pengajuannya. Wewenang otorisasi sendiri tidak berubah — itu tetap mengikuti Approval Group. Perubahan butuh alasan & menunggu approval Admin Approval (dual control).
